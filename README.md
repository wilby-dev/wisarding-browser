🪄 The Marauder’s Arcane Browser
“I solemnly swear that I am up to no good.”

📖 Overview
The Marauder’s Arcane Browser is a Harry Potter-themed web application and custom browser shell. Built with deep mahogany wood textures, antique parchment pages, glowing wizarding runes, and gold trim, it turns web browsing into a magical experience.

✨ Key Features
⚡ Interactive Wand Cursor & Spellcasting:

Custom wand cursor emitting shimmering particle sparks.

Interactive Spellbook / Cast Bar allowing you to cast spells like Lumos, Alohomora, Aguamenti, and Revelio to trigger visual effects and unlock hidden features.

🎵 Built-in Synthesized Audio:

Uses the Web Audio API to synthesize magical chime sounds, spell audio effects, and parchment rustles without requiring external MP3 files.

📜 Multi-Tab Parchment Interface:

Parchment-styled tab manager with dynamic tab creation, smooth switching, and close animations.

🏰 5 Built-in Magical Websites:

The Daily Prophet: Live wizarding news ticker, moving pictures, breaking headlines, and opinion columns by Rita Skeeter.

Hogwarts Restricted Library: Interactive potions lab cauldron simulator and searchable wizarding lore archives.

Diagon Alley Storefront: Interactive shop front connected to a Gringotts Galleons balance wallet where you can purchase supplies.

Quidditch Live Tracker: Pitch match monitor displaying real-time match statistics and play-by-play commentary.

Room of Requirement: Launchpad dashboard featuring quick-access bookmarks, widgets, and customizable shortcuts.
